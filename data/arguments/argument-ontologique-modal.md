premisses:
  - enonce: Il est possible que Dieu (un être maximalement grand, qui existe nécessairement) existe.
  - enonce: S’il est possible que Dieu existe, alors Dieu existe dans au moins un monde possible.
  - enonce: Si Dieu existe dans un monde possible, alors il existe dans tous les mondes possibles (il est nécessaire, et en logique modale S5 ce qui est possiblement nécessaire est nécessaire).
  - enonce: Si Dieu existe dans tous les mondes possibles, il existe dans le monde réel.
conclusion: Dieu existe.
points_faibles:
  - "Tout repose sur la première prémisse : le sceptique répond qu’il est tout aussi « possible » qu’aucun être nécessaire n’existe. Plantinga lui-même présente l’argument comme rationnellement acceptable, non comme une preuve contraignante."
