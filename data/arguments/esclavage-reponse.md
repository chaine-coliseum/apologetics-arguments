1. **Des lois pour Israël** : ces dispositions concernent l’ancienne alliance et ne s’imposent pas aux chrétiens.
2. **La dureté des cœurs** (Mt 19,8 ; Mc 10,5) : Moïse tolère ce qu’il ne peut abolir, comme pour la répudiation.
3. **La révélation progressive** : la Loi est un pédagogue (Ga 3,24).
4. **Une transition difficile** : une économie esclavagiste ne s’abolit pas d’un trait ; une révolte des esclaves aurait été écrasée.
5. **Légiférer n’est pas ordonner** : réglementer une pratique, ce n’est pas la prescrire.
6. **Une avancée pour l’époque** : le maître est puni s’il tue (Ex 21,20) ; l’esclave mutilé est libéré (Ex 21,26-27) ; le rapt d’homme est puni de mort (Ex 21,16) ; l’esclave en fuite ne doit pas être livré (Dt 23,16-17) ; le serviteur hébreu est libéré la septième année.
7. **Le modèle chrétien** : « ni esclave ni libre » (Ga 3,28) ; Onésime est « un frère bien-aimé » (Phm 15-16) ; « Maîtres, accordez à vos serviteurs ce qui est juste » (Col 4,1) ; les « voleurs d’hommes » sont condamnés (1 Tm 1,10).

**Les Pères** : Augustin voit dans l’esclavage une conséquence du péché ; Grégoire de Nysse condamne la possession d’esclaves ; Thomas d’Aquin ne le tient pas pour un ordre naturel. **Le Magistère** : Jean-Paul II, à Gorée (1992), demande pardon pour la traite.
